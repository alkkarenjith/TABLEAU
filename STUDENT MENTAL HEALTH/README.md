This repository contains an interactive "Student Mental Health Dashboard" developed using Tableau to explore and visualize the factors associated with student depression. The dashboard provides a data-driven view of student mental health by analyzing academic pressure, financial stress, study satisfaction, sleep duration, age, gender, city, and degree. 
The dashboard combines KPI cards and interactive visualizations to uncover patterns between academic and lifestyle factors and depression. It includes visual analysis of depression by age, academic pressure, study satisfaction, sleep duration, and financial stress, along with demographic comparisons across gender, city, and degree. 
Interactive filters allow users to dynamically explore the data and identify patterns across different student groups. A key aspect of this project is its focus on connecting academic, financial, lifestyle, and demographic factors within a single interactive dashboard, making complex student mental health data easier to explore and interpret.
This project demonstrates proficiency in Tableau, data visualization, data analysis, interactive dashboard development, KPI design, and insight generation from real-world datasets.
